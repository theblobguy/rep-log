# Rep Log

Workout tracker — log sets, rest timer, plate loader, 3D exercise guides, goal-based sets/reps/rest, progress charts.

Installable web app: open the site in Safari → Share → **Add to Home Screen**. Works offline. Data is stored on the device; use More → Download backup to keep a copy.

Hosted with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
